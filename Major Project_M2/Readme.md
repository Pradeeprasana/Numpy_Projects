🧮 NumPy Mathematical Calculator
📘 Project Overview

The NumPy Mathematical Calculator is a Python-based mini project that demonstrates the power of the NumPy library for performing numerical and statistical computations efficiently.

This program acts as a simple calculator that supports arithmetic operations, statistical analysis, and array manipulation, helping learners understand how NumPy is used in real-world data analysis and scientific computing.

🎯 Objective

To build a Python calculator using the NumPy library that can perform:

Basic arithmetic operations

Statistical operations

Array manipulation

This project helps students practice core NumPy functionalities such as array creation, reshaping, sorting, and applying built-in mathematical functions.

🔧 Key Features
1️⃣ Basic Arithmetic Operations

Addition, Subtraction, Multiplication, Division

Power operations between two arrays

2️⃣ Statistical Operations

Mean, Median, Standard Deviation, Variance

Minimum, Maximum, Sum, Product

Shape, Size, and Data Type analysis

3️⃣ Array Manipulation

Reshaping arrays (when possible)

Sorting and Reverse Sorting

Extracting unique values

Accessing first and last elements

Filtering values greater than the mean

🧩 Technologies Used

Python 3.8+

NumPy Library

💻 How to Run the Project

Install Dependencies

pip install numpy


Run the Program

python numpy_calculator.py


Provide Input

Enter two arrays when prompted (space-separated).

Choose from the menu to perform operations.

🧠 Example
Enter elements of first array separated by space: 10 20 30 40
Enter elements of second array separated by space: 2 4 6 8

===========================
🔧 Select an Operation
1. Basic Arithmetic Operations
2. Statistical Operations (on first array)
3. Array Manipulation (on first array)
4. Exit
===========================

Enter your choice (1-4): 1
